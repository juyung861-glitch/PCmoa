# PCmoa — 같은 네트워크 PC를 브라우저 하나로

같은 네트워크(공유기·사무실 망) 안의 PC 여러 대를 **내 자리 브라우저 한 화면**에서 보고, 명령을 보내고, 파일을 주고받고, 화면까지 조종하는 도구입니다.
외부 서버나 클라우드 없이 **메인 PC 한 대가 서버**가 되고, Windows·Linux 둘 다 지원합니다.

📘 **처음 쓰신다면 [사용자 가이드](docs/USER_GUIDE.md)를 보세요.** 실제 화면으로 설치·연결·기능별 사용법·삭제 방법·문제 해결을 설명합니다.

> ⚠️ **본인 소유이거나 사용 허락을 받은 PC에서만** 사용하세요. 회사·학교 등 기관 망에서는 원격 접속 도구 사용 규정을 먼저 확인하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📋 PC 목록·상태 | 온라인 / 응답 있음 / 응답 없음, CPU·RAM·GPU 사용률 |
| 🔗 링크로 연결 | 연결할 PC에서 링크 열고 버튼 한 번. Windows 계정·비밀번호 입력 없음 |
| ⌨️ 명령·파일 전송 | 원하는 PC(여러 대 동시도 가능)에 명령 실행, 파일 보내기·가져오기 |
| 🖥️ 터미널 | 브라우저 안에서 PowerShell · CMD · WSL · Git Bash / bash · zsh |
| 👀 화면 보기·조종 | 실시간 화면, 마우스·키보드 조종, 글자 클립보드 공유 |
| 🗂️ 그룹 | "개인 공간" / "공공장소"로 PC를 묶고 전원 제어 허용 여부를 따로 설정 |
| 🤖 AI 대화 (선택) | "2번 PC에 파이썬 깔아 줘"처럼 말하면 Claude가 명령을 짜고, **사람이 승인해야만** 실행 |

## 준비물

- **메인 PC** (서버 역할): Windows 또는 Linux, **Python 3.10 이상**
- **연결할 PC**: 메인 PC와 같은 네트워크에 있으면 됩니다. Python이 없어도 됩니다(아래 [Python 없는 PC](#python이-없는-pc-연결하기) 참고).
- AI 대화를 쓰려면 **API 키**가 필요합니다: Claude(Anthropic) · GPT(OpenAI) · Gemini(Google) 중 하나 (안 써도 다른 기능은 전부 동작)

## 1. 메인 PC에서 서버 켜기

### ① 내려받기와 설치 (처음 한 번)

```powershell
git clone https://github.com/juyung861-glitch/PCmoa.git
cd PCmoa
pip install -r requirements.txt
```

> git이 없으면 이 페이지의 **Code → Download ZIP**으로 받아 압축을 풀어도 됩니다.

### ② 서버 켜기

**Windows**: `start_pcmoa.bat` 더블클릭 → 서버가 켜지고 브라우저에 대시보드가 열립니다.

**Linux 또는 직접 실행**:
```bash
cd server
python app.py
```
→ 브라우저에서 `http://127.0.0.1:8000` 열기

### ③ 처음 로그인

첫 실행 때 **관리자(admin) 비밀번호가 서버 창에 한 번만** 표시됩니다.
- Windows에서 `start_pcmoa.bat`으로 켰다면 작업 표시줄의 **"PCmoa 서버"** 창(최소화됨)을 열어 확인하세요.
- 로그인 후 **설정 → 내 비밀번호 변경**에서 바로 바꾸는 걸 추천합니다.
- 비밀번호를 잊었다면: `cd server` → `python app.py reset-admin`

### ④ 방화벽 열기 (Windows, 처음 한 번)

다른 PC가 메인 PC에 접속하려면 8000번 포트를 열어야 합니다. **관리자 PowerShell**에서:

```powershell
New-NetFirewallRule -DisplayName "PCmoa" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

> Windows가 처음 실행할 때 "액세스 허용" 창을 띄우면 **개인 네트워크**에 체크하고 허용해도 됩니다.

## 2. 다른 PC 연결하기

1. 메인 PC 대시보드 **오른쪽 상단의 ⚡ PC 연결**을 누릅니다.
2. 그 PC를 부를 **이름**을 적고(필요하면 넣을 그룹도 선택) **[연결 코드 발급]**을 누릅니다.
3. 6자리 번호 아래에 **연결 링크**가 나옵니다 → **[복사]**
   (예: `http://192.168.0.10:8000/connect?code=123456`)
4. **연결할 PC**의 브라우저에 그 링크를 붙여 넣고 → **[연결 시작]** → 받은 파일(`connect-123456.cmd`)을 실행합니다.
5. 끝! 메인 PC 대시보드에 그 PC 카드가 나타납니다.

- 연결 코드는 **10분 동안, 한 번만** 쓸 수 있습니다.
- 연결 프로그램은 로그인할 때 자동으로 켜지도록 등록됩니다. 한 번 연결하면 다음부터는 아무것도 안 해도 됩니다.
- Windows가 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

### 메인 PC 자신도 목록에 넣기

**⚡ PC 연결 → [메인 PC 추가]**를 누르면 코드 없이 바로 등록됩니다.

### Python이 없는 PC 연결하기

메인 PC에 Python 실행 파일을 한 번만 넣어 두면, 연결할 PC에 Python이 없어도 자동으로 처리됩니다.

1. https://www.python.org/downloads/windows/ 에서 **Windows embeddable package (64-bit)** zip을 받습니다 (약 11MB).
2. 이름을 `python-embed.zip`으로 바꿔서 메인 PC의 `server/` 폴더에 넣습니다.

그러면 연결할 PC의 `%LOCALAPPDATA%\PCManager` 폴더에만 Python이 풀리고, 시스템에는 설치되지 않습니다.

### 직접 연결하기 (링크 대신)

연결할 PC에 이 저장소의 `agent/agent.py`가 있다면:

```bash
python agent.py --server http://192.168.0.10:8000 --code 123456
```

## 3. 사용하기

PC 카드의 버튼으로 대부분의 기능을 씁니다.

| 버튼 | 하는 일 |
|---|---|
| **명령** | PowerShell/bash 명령 실행. 파일을 끌어다 놓으면 그 PC의 `~/pcmanager/inbox/`로 전송 |
| **터미널** | 브라우저 안 터미널. 위쪽에서 셸 선택(PowerShell · CMD · WSL · Git Bash 등) |
| **화면** | 실시간 화면 보기. **조종**을 켜면 마우스·키보드 사용. 새 창으로 띄울 수 있음 |
| **파일** | 그 PC 폴더를 둘러보고 파일 / 폴더(zip)를 내 PC로 받기 (최대 4GB) |
| **⏻ 전원** | 끄기·재부팅. "공공장소" 그룹은 기본적으로 막혀 있음 |
| **⋯ 관리** | 이름 변경, 그룹 이동, 이 PC 기록 보기, 원격 접속 끄기, 삭제 |

- 여러 카드를 체크한 뒤 **선택 PC에 명령**으로 한꺼번에 실행할 수 있습니다.
- 모든 명령·파일 전송·화면 보기는 **명령 기록 / 활동 로그**에 남습니다.
- 같은 네트워크의 어느 PC에서든 `http://메인PC주소:8000`을 열면 같은 대시보드를 쓸 수 있습니다(로그인 필요).
- Chrome/Edge 주소창 오른쪽 **[앱 설치]**를 누르면 앱처럼 작업 표시줄에 고정할 수 있습니다.

### AI 대화 (선택)

1. **설정 → 내 API 키**에 API 키를 넣고 **연결 확인**. Claude(`sk-ant-…`) · GPT(`sk-…`) · Gemini(`AIza…`) 키를 쓸 수 있고, 어느 서비스인지는 자동으로 알아냅니다.
2. 사이드바 **AI 대화** → 새 대화 → 하고 싶은 일을 말로 적기
3. Claude가 명령을 제안하면 **승인 카드**에서 확인·수정한 뒤 실행

- **수동 모드**: 모든 명령을 묻습니다. **자동 모드**: 안전한 명령만 바로 실행하고, 삭제·종료·설치·레지스트리 변경 등은 항상 묻습니다.
- API 키는 계정별로 암호화되어 `server/api_keys/`에 저장되며, Git에 올라가지 않습니다.
- 화면 보기·명령·터미널은 API를 쓰지 않습니다. 토큰은 AI 기능에서만 씁니다.

## 연결 해제와 삭제

- 잠깐 막기: 카드의 **원격 접속 끄기**
- 목록에서 빼기: 카드 **⋯ → 목록에서 삭제**
- 연결한 PC에서 완전히 지우기: 그 PC의 연결 프로그램 폴더에서 `python agent.py --uninstall` 후 폴더 삭제
  (Windows 링크 방식은 `%LOCALAPPDATA%\PCManager`)

자세한 순서와 메인 PC 삭제 방법은 [사용자 가이드 3장](docs/USER_GUIDE.md#3-연결-해제와-완전-삭제)에 있습니다.

## 보안

- **연결은 양쪽 동의가 있어야** 합니다. 메인 PC에서 발급한 10분짜리 1회용 코드가 있어야만 PC가 등록됩니다.
- **화면을 보고 있으면 상대 PC에 표시**됩니다("'계정' 계정이 이 PC 화면을 보고 있습니다"). 연결 프로그램 창은 숨겨지지 않습니다.
- 비밀번호는 PBKDF2-SHA256(60만 번 반복, 계정별 솔트)으로 저장, 로그인 5회 실패 시 잠금.
- 계정마다 PC·기록·API 키가 완전히 분리되고, 권한은 admin / operator / viewer 3단계입니다.
- PC마다 다른 토큰을 쓰고, 보낸 파일은 SHA-256으로 확인합니다.
- 그 PC에서 화면 보기를 아예 막으려면 연결 프로그램을 `--no-screen`으로 실행하세요.

**아직 부족한 점**
- 통신이 **HTTP**입니다(같은 네트워크 안 사용 전제). 공용 와이파이처럼 믿을 수 없는 네트워크에서는 쓰지 마세요. HTTPS는 다음 단계 예정입니다.
- 인터넷에 서버 포트를 열어 외부에서 접속하는 용도로 만들지 않았습니다.

## 알려진 제한

- 화면 조종: UAC 확인 창·잠금 화면·Ctrl+Alt+Del 화면은 조종할 수 없습니다(Windows 보안). 관리자 권한 창은 [관리자 권한으로 전환] 후 가능.
- 터미널(연결 프로그램 경로)은 줄 단위라 vim·top 같은 전체 화면 프로그램은 제한됩니다.
- Linux 화면 보기는 X11 세션이 필요합니다(Wayland 불가).
- 주 모니터만 보입니다.

## 폴더 구조

```
PCmoa/
├─ start_pcmoa.bat        Windows: 서버 켜고 대시보드 열기
├─ make_shortcut.bat      Windows: 바탕화면 바로가기 만들기
├─ server/
│  ├─ app.py              서버 (FastAPI)
│  └─ static/index.html   대시보드
├─ agent/agent.py         연결 프로그램 (각 PC에서 실행, Windows/Linux 공통)
├─ docs/CHANGELOG.md      버전별 변경 기록
└─ requirements.txt
```

첫 실행 때 `server/config.json`, `server/pcs.db`, `server/api_keys/` 등이 생깁니다. 비밀 정보가 들어 있으니 공유하지 마세요(.gitignore 처리됨).

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 다른 PC에서 링크가 안 열림 | 메인 PC 방화벽 8000 포트, 두 PC가 같은 네트워크인지 |
| 카드가 "응답 없음" | 그 PC가 켜져 있는지, 연결 프로그램 창이 떠 있는지(그 PC의 `agent.log` 확인) |
| 화면이 안 옴 | 화면 창에 이유가 표시됨. 예전 버전이면 [원격으로 업데이트] |
| AI 연결 확인 실패 | 설정의 단계별 진단 결과 확인. 기관 망 SSL 검사 때문이면 `pip install truststore` 후 서버 재시작 |

버그나 제안은 [Issues](https://github.com/juyung861-glitch/PCmoa/issues)에 남겨 주세요.
