1. 추가할 PC의 IP·MAC 주소 확인하기

추가하려는 그 PC에서 PowerShell(또는 Linux 터미널)을 열고:

ipconfig /all          # Windows
ip addr                # Linux

결과에서 "이더넷 어댑터 이더넷"(무선이면 "Wi-Fi")을 찾습니다. vEthernet (WSL), VMware, VirtualBox 같은 가상 어댑터는 무시하세요.

ipconfig 항목PC 추가 칸예시
IPv4 주소IP 주소192.168.0.11
물리적 주소MAC 주소A1-B2-C3-D4-E5-F6 (하이픈·콜론 모두 가능)
호스트 이름 (맨 위 "Windows IP 구성")호스트명 / 이름office-pc-02

한 줄로 뽑으려면 (Windows):

Get-NetIPConfiguration | Where {$_.IPv4DefaultGateway} | Select InterfaceAlias, IPv4Address
Get-NetAdapter | Where Status -eq Up | Select Name, MacAddress

IP만 있어도 상태 확인은 됩니다. MAC은 "켜기"(Wake-on-LAN)에만 필요합니다.

2. 옆 PC IP 빠르게 추정하기

이 서버 PC는 -, 호스트명 -입니다. 호스트명 끝 번호와 IP 끝자리가 같은 망이면 옆 PC는 -.자리번호로 바로 넣어 볼 수 있습니다.

켜져 있는 PC만 보려면 이 PC에서:

Get-NetNeighbor -AddressFamily IPv4 | Where {$_.IPAddress -like '-.*' -and $_.State -ne 'Unreachable'} | Select IPAddress, LinkLayerAddress

LinkLayerAddress가 그 PC의 MAC 주소라, 옆 PC에 가지 않고도 IP와 MAC을 한 번에 얻습니다.

3. 연결 방식은 하나 — "자동"

PC를 추가할 때 방식을 고를 필요가 없습니다. 서버가 5초마다 아래 순서로 되는 경로를 골라 카드 배지에 표시하고, 명령·파일은 그 경로로 갑니다. 사람은 계정(사용자명·비밀번호)만 넣어 두면 됩니다.

순서경로상대 PC에 필요한 것할 수 있는 것
1에이전트agent 폴더 + Python, 1회 등록상태(CPU·메모리), 명령, 파일, 끄기/재부팅. 계정 불필요, 아웃바운드만 써서 방화벽에 강함
2SSHOpenSSH 서버 켜기 (Linux 기본, Windows는 아래 5번). 설치 없음명령, 파일, 끄기/재부팅
3PowerShell 원격 (WinRM)Windows 기본 기능. 관리자 PowerShell에서 Enable-PSRemoting -Force 한 줄명령, 파일(10MB까지), 끄기/재부팅
4상태만없음ping·포트로 응답 여부만. 명령 버튼 비활성

특정 경로만 쓰고 싶으면 편집에서 "에이전트만 / SSH만 / PowerShell 원격만 / 상태만"으로 고정할 수 있습니다. PowerShell 원격은 같은 워크그룹의 로컬 계정이면 상대 PC에서 Set-Item WSMan:\localhost\Client\TrustedHosts -Value '-' 이 추가로 필요할 수 있습니다.

4. 가장 쉬운 연결 — "PC 연결" 코드

상단 ⚡ PC 연결 → 이름 입력 → 6자리 코드. 화면에 뜨는 주소(http://-:8000/connect?code=숫자)를 연결할 PC에서 열고 "연결 시작" → 받은 파일을 실행하면 끝입니다. 주소·코드 입력 없음. Windows 계정·비밀번호가 필요 없고, 자동 시작까지 등록됩니다. (아래는 관리자용 일괄 등록 방법)

4-1. 관리자용 — 등록 토큰으로 일괄 등록

① 메인 PC(서버)에서 방화벽 8000 포트 허용 — 관리자 PowerShell:

New-NetFirewallRule -DisplayName "PC Manager" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow

② 다른 PC에 agent 폴더를 복사하고 최초 1회 등록:

pip install psutil
python agent.py --server http://-:8000 --enroll (관리자만 표시)

등록되면 그 PC 전용 토큰이 agent.json에 저장되고, 이후엔 python agent.py --server http://-:8000 만으로 실행됩니다. 토큰은 설정 탭의 PC 목록에서 언제든 폐기·재발급할 수 있습니다.

Linux도 같습니다. 부팅 시 자동 실행은 Windows 작업 스케줄러 / Linux systemd에 등록하세요 (2차).

5. 계정 방식 — 상대 PC에 OpenSSH 또는 PowerShell 원격 켜기

가장 쉬운 길 (Windows): 관리자 PowerShell에서 Enable-PSRemoting -Force 한 줄. 설치 없이 바로 됩니다. 그다음 PC 추가에서 계정만 넣으면 경로가 "PS원격"으로 잡힙니다.

SSH를 쓰려면:

Windows (관리자 PowerShell):

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
Start-Service sshd; Set-Service sshd -StartupType Automatic
New-NetFirewallRule -Name sshd -DisplayName "OpenSSH" -Direction Inbound -Protocol TCP -LocalPort 22 -Action Allow

Linux: sudo apt install openssh-server (대부분 기본 설치).

그다음 PC 추가/편집에서 사용자명(그 PC의 로그인 계정), 비밀번호 또는 메인 PC에 있는 개인키 경로(예: C:\Users\me\.ssh\id_ed25519)를 넣습니다. 비밀번호는 암호화해 저장되며 화면에 다시 표시되지 않습니다. 키 인증을 권장합니다.

6. 명령·파일 전송

  • 카드의 명령 버튼 → 명령을 입력하고 실행. Windows는 PowerShell, Linux는 bash로 돌고 출력이 돌아옵니다 (기본 60초 제한).
  • 같은 창에서 파일을 끌어다 놓으면 상대 PC의 ~/pcmanager/inbox/에 저장됩니다 (100MB 이하, SHA-256 검증). 받은 파일은 명령으로 바로 실행할 수 있습니다: python inbox/run.py
  • 카드 왼쪽 체크박스로 여러 PC를 고르면 상단 "선택 PC에 명령"으로 한 번에 보냅니다. 실행 전에 대상 목록을 확인합니다.
  • 모든 명령은 명령 기록 탭에 요청자·대상·시각·종료 코드·출력과 함께 남습니다.

7. "켜기"(Wake-on-LAN)가 안 될 때

  • MAC 주소가 등록돼 있어야 버튼이 활성화됩니다
  • 상대 PC BIOS의 Wake on LAN, 장치 관리자 → 네트워크 어댑터 → 전원 관리의 "매직 패킷으로 절전 해제"가 켜져 있어야 합니다
  • 같은 서브넷에서만 동작합니다
